# Digital Archive Pro

برنامج محلي لإدارة أرشيف المراسلات الواردة والصادرة، مع التوقيع الثابت `© Noureddine 2026`.

## حالة هذا الفرع

فرع تطوير معزول: `work/pro-recovering-implementation-2026-10-17`. **ليس إصدارًا نهائيًا أو حزمة تشغيل مستقلة.** يحتوي المستودع على المصدر، ولم تُبنَ في هذه البيئة حزمة Portable موثقة من أحدث التعديلات. لا تعدّل `main` ولا تعتمد هذا الفرع للإنتاج قبل اكتمال التحقق.

## التشغيل من المصدر

- يتطلب Python 3.8 أو أحدث مثبتًا على الجهاز.
- شغّل `python app.py` أو ملف BAT المرفق.
- الخدمة محلية على `127.0.0.1` فقط.
- الوظائف الأساسية للأرشيف محلية ولا تتطلب اتصالًا بالإنترنت.
- قاعدة البيانات `archive.db` بجوار البرنامج؛ ومسار الأرشيف الرقمي قابل للتحديد من الإعدادات.
- لا تحذف قاعدة البيانات أو مجلد الأرشيف يدويًا إن كنت تريد الاحتفاظ ببياناتك.

## الميزات الأمنية المضافة في فرع التطوير

- أداة ربط PDF تُفتح من زر داخل الإعدادات، دون عنصر في القائمة الجانبية.
- مطابقة أسماء الملفات فقط، عبر السنوات والوحدات، مع معاينة وتأكيد صريح قبل إنشاء الروابط.
- لا OCR ولا قراءة لمحتوى PDF، ولا نقل أو حذف للملفات الأصلية. فك الارتباط يحذف علاقة قاعدة البيانات فقط.
- لا تشغيل تلقائي لربط PDF.
- إنذار صوتي محلي متكرر لوسائط USB/الشبكة المحلية حتى الإقرار، وإيقاف آمن يسمح للطلبات الجارية بالانتهاء.
- عند تفعيل مراقبة الإنترنت، يؤدي اكتشاف اتصال خارجي فعلي إلى إيقاف آمن، وإغلاق جلسة Chrome الخاصة بالبرنامج فقط؛ لا يستهدف جلسة Chrome الشخصية.

## الاختبارات

من جذر المستودع، بعد توفير Python:

```text
python -m py_compile app.py tests/qa_smoke.py tests/test_safety_guards.py tests/windows_qa.py
python -m unittest discover -s tests -p "test_*.py" -v
python tests/qa_smoke.py
python tests/windows_qa.py
```

**تنبيه:** إضافة الاختبارات إلى المستودع لا تعني أنها نُفّذت. حالة هذا الفرع حتى آخر تحديث: الاختبارات والبناء لم تُنفّذ في بيئة تشغيل قابلة للوصول. تقرير فحص Windows 7 يجب أن يُنفّذ على جهاز Windows 7 SP1 بنظام 32 بت؛ فحص Linux أو فحص المصدر لا يثبت التوافق الأصلي.

راجع `IMPLEMENTATION_STATUS_AR.md` لحالة التنفيذ والتحقق الحالية.

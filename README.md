# Digital Archive Pro

برنامج محلي لإدارة أرشيف المراسلات الواردة والصادرة.

> **حالة هذا الفرع:** فرع تجربة وتنقيح معزول `work/digital-archive-pro-verified-base-2026-10-12`. لا يُعدّ إصدارًا نهائيًا، ولم يُدمج في `main`.

## التشغيل من المصدر

- Python 3.8 أو أحدث.
- شغّل `python app.py`.
- يبدأ الخادم على واجهة loopback المحلية `127.0.0.1` ويفتح المتصفح بعد جاهزية الخدمة.
- لا يفحص البرنامج أجهزة الشبكة الأخرى ولا يرسل محتويات الأرشيف إلى خدمات خارجية تلقائيًا.
- لا يحتاج تشغيل الأرشفة المحلية إلى اتصال بالإنترنت.

## البيانات والتخزين

- قاعدة البيانات: `archive.db` بجوار البرنامج.
- مسار الأرشيف الرقمي قابل للتحديد من الإعدادات؛ المسار الافتراضي `documents`.
- النسخ الرقمية الجديدة تُنظّم وفق: السنة ← مكان التخزين ← الوحدة ← وارد/صادر.
- نماذج المراسلات في مجلد مستقل قابل للتحديد، ولا تُنسخ تلقائيًا إلى أرشيف الصادر.
- إعادة الضبط الشاملة تتطلب تأكيدًا بمسار الأرشيف نفسه، وتُبقي حسابات المستخدمين والبرنامج ونماذج المراسلات.

## الاختبارات

نفّذ من جذر المشروع:

```text
python -m py_compile app.py tests/qa_smoke.py tests/test_safety_guards.py tests/windows_qa.py
python -m unittest discover -s tests -p "test_*.py" -v
python tests/qa_smoke.py
python tests/windows_qa.py
```

- `qa_smoke.py` يختبر HTTP المحلي، التخصيص، المسارات، إنشاء المجلدات، المرفقات، النسخ الاحتياطي والاستعادة، وإعادة الضبط باستخدام قاعدة بيانات مؤقتة.
- `windows_qa.py` ينشئ تقريرًا باسم `Windows_Compatibility_QA_Report.txt` ولا يلمس قاعدة بيانات المستخدم.
- يوجد فحص CI باستخدام Python 3.8 بنسختي 32-bit و64-bit. **هذا لا يثبت وحده التوافق الأصلي مع Windows 7**؛ يجب تشغيل فحص محلي على Windows 7 SP1 ‏32-bit فعليًا قبل إعلان ذلك التوافق.
